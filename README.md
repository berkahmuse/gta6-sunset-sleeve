# Sunset Sleeve — Diagonal Duotone Cover Maker

[![Bounty](https://make.fun/badge/gta6-cover-art-01.svg)](https://make.fun/bounty/gta6-cover-art-01)
[![Rank](https://make.fun/badge/gta6-cover-art-01/berkahmuse/gta6-sunset-sleeve/rank.svg)](https://make.fun/bounty/gta6-cover-art-01/leaderboard)
[![Reward](https://make.fun/badge/gta6-cover-art-01/berkahmuse/gta6-sunset-sleeve/reward.svg)](https://make.fun/bounty/gta6-cover-art-01)

**Sunset Sleeve** cuts your photos into bold diagonal slices, grades every slice with a duotone gradient map, and wraps the cover in a vertical title spine — no grid, no frames, just slanted neon heat.

- **Layouts:** Diagonal Trio (three slanted slices), Film Strip (four angled frames), Duo Split (two bold halves)
- **Grades:** Teal-Pink Neon, Sunset Amber, Ultraviolet, Mint Noir — each panel is re-mapped pixel by pixel, shadows to highlights
- **Your photos stay yours:** upload up to 6 photos, assign them to slices, drag to reposition, scroll or slide to zoom — everything is read locally, nothing is ever uploaded
- **Words:** editable title and subtitle in heavy condensed lettering with stroke and gradient fill, a neon double rule, and a heat-star badge
- **Export:** PNG at 1080×1080, 1080×1350, or 1920×1080
- Four built-in sample scenes (two painted procedurally) fill the slices the moment the editor opens. Fully static, works offline, no build step.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Build the submission dossier:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
